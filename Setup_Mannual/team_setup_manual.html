🔰 First Time Setup (Naye Person Ke Liye Complete Steps)

Agar aap pehli baar is repo par kaam kar rahe hain, to sequence me in 5 steps ko follow karein:

Step 1: Clone Repository & Open Folder
Git repo clone karein aur project directory me jayein:
PowerShell / Git Bash 
git clone <YOUR_GITHUB_REPO_URL>
cd LandRecords_extracted
Step 2: Environment Variables (.env.local) Banayein
Security ke liye .env.local Git me commit nahi hota. Repo me client/.env.example di gayi hai, use copy karke apni file banayein:
Terminal 
cd client
cp .env.example .env.local
⚠️
client/.env.local me ye zaroori keys check karein:
• MONGODB_URI = Aapka MongoDB Atlas connection string (DB: elandrecords)
• NEXT_PUBLIC_FABRIC_API_URL = http://localhost:3001
• NEXT_PUBLIC_BASE_URL = http://localhost:3000
• PINATA_API_KEY, PINATA_SECRET_KEY, PINATA_JWT = Pinata IPFS keys (agar empty hai to fallback hashes use honge)
• SMTP_USER, SMTP_PASSWORD = Email OTP ke liye (Development me OTP console log me bhi show hota hai)
Step 3: Dependencies Install Karein (Client & Fabric API)
Dono folders me NPM packages install karein:
1. Client Dependencies 
cd client
npm install
2. Fabric API Dependencies 
cd ../fabric-api
npm install
Step 4: Database Me Default Users & Officials Seed Karein
MongoDB ke andar Super Admin aur government officials (Clerk, MRO, Surveyor, Collector) insert karein:
client/ folder me Terminal 
cd client

# 1. Super Admin banayein (admin@elandrecords.gov / admin123)
node create-admin.js

# 2. Saare Officials banayein (Clerk, Surveyor, MRO, Collector)
node create-officials.js
✅
Output me "Connected to MongoDB" aur "Done!" ka message dikhega.
Step 5: Run ./setup-network.sh (Hyperledger Fabric Initialize)
Ye script 3 organizations (Org1, Org2, Org3) ke cryptographic certs banati hai, channel create karti hai, Docker containers launch karti hai, aur Smart Contract (land-registration-contract.js) deploy karti hai:
WSL 2 (Ubuntu) / Git Bash - Root Folder 
# Project root folder me jayein
cd /path/to/LandRecords_extracted

# Executable permissions dein
chmod +x setup-network.sh *.sh

# Network setup run karein (Takes 2-4 minutes)
./setup-network.sh
ℹ️
Important: Ye script sirf ek baar (pehli baar) chalani hoti hai. Roz-roz isko run nahi karna hai!

📜 Shell Scripts Comparison (Kab Kaunsi Script Chalani Hai?)

Project me teen mukhya bash scripts hain: setup-network.sh, start-network.sh, aur start-only.sh. Niche simple terms me unka farak aur purpose samjhaya gaya hai:

Script Name Kab Chalani Hai? (When to Use) Ye Kya Karti Hai? (What it Does) Fabric API Chalu Karti Hai? Data Pe Asar (Data Safety)
./setup-network.sh Sirf Pehli Baar (Day 1) ya jab poora blockchain network scratch se reset karna ho. Purane containers & crypto delete karke fresh certificates banati hai, genesis block create karti hai, 3 Orgs ke peers aur CouchDB launch karti hai, aur Smart Contract deploy karti hai (takes 2-4 mins). Nahi ⚠️ Data Wipe Hoga
Purana ledger erase ho jata hai
./start-network.sh Jab aapko sirf Docker network start karna ho aur fabric-api ko alag terminal me chalana ho taaki live logs monitor kar sakein. Band pade existing containers ko docker start karti hai (~5 seconds) aur Admin cert symlinks dynamically fix karti hai. Nahi (Manually chalu karo) ✅ 100% Data Safe
Ledger ka data bacha rehta hai
./start-only.sh ROZ (Daily Routine) ke liye sabse best! Roz kaam ya demo start karne ke liye sirf yahi ek script chalani hai. Existing containers start karti hai + certs fix karti hai + fabric-api ko automatically background me port 3001 par launch karti hai + healthcheck verify karti hai. ✅ Haan (Port 3001 par Live) ✅ 100% Data Safe
Ledger ka data bacha rehta hai
1. setup-network.sh — The Initializer
Run Only Once (Day 1)

Kyun banayi gayi hai? Hyperledger Fabric ko run karne ke liye crypto material (MSP certificates), channel genesis block, CouchDB state databases aur chaincode package ki zaroorat hoti hai. Ye script in sabhi heavy tasks ko automate karti hai.

⚠️
Rule: Agar aap roz ./setup-network.sh chalaoge to aapke purane sabhi registered land records aur blockchain transactions erase ho jayenge! Isliye ise sirf pehli baar chalayein.
2. start-network.sh — The Network Resumer
For Developers & Debuggers

Kyun banayi gayi hai? Jab network band ho (stopped state me), to naye containers banane ki zaroorat nahi hoti. Ye script sirf docker start command se existing containers ko wake-up karti hai aur cert symlinks verify karti hai.

👉 Kab use karein: Jab aapko cd fabric-api && npm start ek alag terminal window me kholna ho taaki terminal par har ek REST API request aur error log live print hota dikhe.
3. start-only.sh — The 1-Step Daily Starter
Recommended Daily Command

Kyun banayi gayi hai? Developers ka time bachane ke liye. Aapko containers alag start karne aur fabric-api alag start karne ki zaroorat nahi padti. Ye script containers bhi start kar deti hai aur background me node index.js chala kar port 3001 par healthcheck verify kar leti hai.

👉 Kab use karein: Jab bhi aap roz subah ya sham project me frontend ya UI test karna chahte ho. Sirf ek bar ./start-only.sh run karo aur kaam shuru!

🛑 Network Ko Stop Kaise Karein (Shutdown Guide)

Kaam khatam hone ke baad RAM aur CPU free karne ke liye network stop karna zaroori hai. Hamesha Safe Stop use karein:

🟢 Option A: Safe Stop (Data Safe / Recommended)
100% Ledger Safe

Ye script fabric-api process ko kill karti hai aur Hyperledger Docker containers ko cleanly docker stop karti hai. Aapka saara registered land data aur blocks safe rehte hain!

WSL 2 / Git Bash (Root Dir) 
./stop-network.sh
Windows PowerShell (Root Dir) 
.\stop-network.ps1
✨ Agle din dobara chalu karne ke liye sirf ./start-only.sh chalana hoga!
🔴 Option B: Factory Wipe (Destructive Reset)
Ledger Delete Hoga

⚠️ Khatra: Is command se Docker containers, volumes, crypto certificates aur channel destroy ho jayenge:

WSL 2 / Git Bash 
cd fabric-samples/test-network
./network.sh down
🚫
Isko roz mat chalana! Ise sirf tab chalana jab aapko blockchain ko 0 se destroy karke dubara ./setup-network.sh chalani ho.
