Revenue verification. Role check: officer/admin. Verify ke baad history entry — TxID ke saath, immutable (kabhi delete nahi).

Part C: RAFT Consensus — Kya Hai?

RAFT Simple Explanation
5 log committee mein hain. Decision ke liye majority (3+) agreement chahiye. RAFT bhi yahi karta hai.

Nodes mein se ek "Leader" banta hai → transactions order karta hai → baaki "Followers" agree karte hain.

Is project mein:
• 3 Orderer nodes (RAFT se)
• 1 node down bhi ho → 2 majority se kaam chalega
• Leader fail → automatic new leader election
• Hyperledger ka most reliable consensus mechanism
Transaction ke 5 Steps
  1. Propose: fabric-api → Peer nodes ko proposal
  2. Endorse: Peers chaincode run, valid ho to sign (Endorsement Policy)
  3. Order: RAFT transactions ko order karta hai
  4. Commit: Block saare peers ko distribute
  5. Done ✅: TxID wapas → MongoDB update → Email

Kyun Tamper Nahi Ho Sakta?
Koi Block#3 ka data change kare → Block#3 ka hash badal → Block#4 ka prevHash match nahi karega → poori chain invalid. Plus 3 alag Orgs same ledger rakhti hain — teeno ki agreement chahiye valid transaction ke liye.

DOUBT 4 — 3 STORAGE SYSTEMS

MongoDB + Blockchain + IPFS — Kaun Sa Data Kahan Aur Kyun?

Teeno ka alag kaam hai — ek bhi hatao to system toot jaata. Ye intentional architectural decision hai.

🍃
MongoDB Atlas
Kya: User profiles, Form data, Status tracking, Action history, Sessions, DigiLocker vault, Officials, Admin accounts

Kyun: Fast queries. Status baar baar change hota hai. Flexible schema. UI ko quickly data chahiye.
⛓️
Hyperledger Fabric
Kya: Application creation txn, Har official action (TxID+timestamp), Survey data, Encrypted user data, Final approval record

Kyun: Tamper-proof, immutable. 3 orgs validate. Legal proof — koi record delete/change nahi ho sakta.
📌
IPFS (Pinata Cloud)
Kya: Land document PDF, Survey boundary map, Field photos, Patta certificate PDF, DigiLocker documents

Kyun: Large files blockchain pe store nahi hoti. IPFS se unique hash (CID) milta hai jo blockchain pe store hota hai — integrity proof.
