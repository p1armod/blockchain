⚡ Quick Overview

What Does This Project Require?

The project consists of 3 tiers: Blockchain (Hyperledger Fabric v2.4/v2.5), Middleware API (Express), and Client Web App (Next.js 16 + React 19). Below is the complete manifest of every URI, key, and port.

💡
Database Name Consistency Warning
In client/src/lib/db/connect.ts, the default fallback is eland-records (with a hyphen), while in create-officials.js and fix-credentials.js, the script connects to elandrecords (no hyphen). To ensure your seeded admin and officials appear in the frontend, define MONGODB_URI=mongodb://localhost:27017/elandrecords in client/.env.local.

📝 Copy-Paste Configuration #1

Content for client/.env.local

Create a new file named .env.local inside the client/ folder and paste the following content:

client/.env.local 
# ==============================================================================
# 1. DATABASE CONFIGURATION (MANDATORY)
# Use local MongoDB (port 27017) or replace with MongoDB Atlas cloud URI
# ==============================================================================
MONGODB_URI=mongodb://localhost:27017/elandrecords

# ==============================================================================
# 2. INTERNAL API AND BLOCKCHAIN BRIDGE
# ==============================================================================
NEXT_PUBLIC_FABRIC_API_URL=http://localhost:3001
NEXT_PUBLIC_BASE_URL=http://localhost:3000

# ==============================================================================
# 3. IPFS STORAGE (PINATA CLOUD)
# Free tier at https://pinata.cloud (If omitted, system generates mock Qm... hash)
# ==============================================================================
PINATA_API_KEY=your_pinata_api_key_here
PINATA_SECRET_KEY=your_pinata_secret_key_here
PINATA_JWT=your_pinata_jwt_token_here

# ==============================================================================
# 4. EMAIL / SMTP NOTIFICATIONS (OTP VERIFICATION)
# In development (NODE_ENV=development), OTP is returned in API & logged to console.
# For live emails, provide Gmail or Mailtrap SMTP credentials below.
# ==============================================================================
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=your_email@gmail.com
SMTP_PASSWORD=your_16_digit_app_password
SMTP_PASS=your_16_digit_app_password
SMTP_FROM="E-Land Records" <noreply@elandrecords.local>

# Environment
NODE_ENV=development

🔑 Step-by-Step Acquisition

How to Obtain Every URI & API Key

Here is the exact step-by-step procedure to generate or find each credential.

🍃
MongoDB URI
Essential
Choice 1: Local MongoDB (Fastest)
  • Download & install MongoDB Community Server.
  • Runs locally at mongodb://localhost:27017/elandrecords.
  • Or with Docker: docker run -d -p 27017:27017 --name mongo-land mongo:latest
Choice 2: Free MongoDB Atlas Cloud
  • Go to mongodb.com/atlas & register.
  • Create a free M0 Shared Cluster (Free tier).
  • Under Database Access, add a user (e.g. dbuser / password123).
  • Under Network Access, click Add IP & choose Allow Access from Anywhere (0.0.0.0/0).
  • Click Connect → Drivers → Copy URI:
    mongodb+srv://<user>:<pass>@cluster0.xxx.mongodb.net/elandrecords?retryWrites=true&w=majority
📌
Pinata IPFS Cloud
Free 1GB
Pinata hosts land deed PDFs, survey reports, and DigiLocker documents on the decentralized IPFS network.
  • Sign up for a free account at pinata.cloud.
  • Log in and open the API Keys section from the left sidebar.
  • Click New Key.
  • Toggle Admin (or select pinFileToIPFS and pinList).
  • Give it a key name (e.g., LandRecords-PBL) and click Generate API Key.
  • Important: A modal will display 3 values:
    • API Key → PINATA_API_KEY
    • API Secret → PINATA_SECRET_KEY
    • JWT → PINATA_JWT
    Copy them immediately (they are shown only once!).
* If you test without Pinata, the app automatically generates mock hashes (Qm...).
✉️
SMTP Email & OTP
Free
Citizen registration sends 6-digit email OTPs.
  • Option A (Gmail App Password):
  • Open your Google Account → Security.
  • Ensure 2-Step Verification is ON.
  • Search for App passwords.
  • Create an app named LandRecords & copy the 16-character generated password.
  • Set SMTP_USER=yourname@gmail.com and SMTP_PASSWORD=your_16_char_password.
  • Option B (Mailtrap Test Inbox):
  • Go to mailtrap.io (Free).
  • Create an inbox and copy the SMTP credentials directly.
* Note: In development mode, the OTP is returned directly in the register API JSON response and logged to console!
🚀 Execution Workflow

Step-by-Step Sequence to Run the Project

Follow these steps in order to start all blockchain nodes, initialize the database, launch the API, and run the frontend.

1
Start MongoDB Service Terminal #1

Ensure your local MongoDB daemon is running on port 27017, or verify your MongoDB Atlas cluster is online.

# If using Docker for MongoDB: docker run -d -p 27017:27017 --name mongo-land mongo:latest
2
Seed Default Admin & Government Officials Terminal #1

Initialize the database with the Super Admin and official accounts (Clerk, MRO, Surveyor, Collector, etc.).

cd c:\Users\hmury\Desktop\LandRecords_PBL\25CSMR09\LandRecords_extracted\client node create-admin.js node fix-credentials.js
3
Start Hyperledger Fabric 3-Org Network WSL2 / Git Bash

Since Hyperledger Fabric relies on Docker and Linux bash scripts, run this in WSL2 (Ubuntu) or Git Bash:

# From LandRecords_extracted directory: chmod +x *.sh ./start-network.sh # (Or run ./setup-network.sh if initializing the network for the first time)
4
Start Fabric REST API Gateway (Port 3001) Terminal #2

This starts the Express server that routes requests from the Next.js UI to the blockchain peers using the Fabric SDK.

cd c:\Users\hmury\Desktop\LandRecords_PBL\25CSMR09\LandRecords_extracted\fabric-api npm install npm start
✔ Will output: Fabric API server running on port 3001
5
Start Next.js Client Web App (Port 3000) Terminal #3

Launch the user and official portal frontend:

cd c:\Users\hmury\Desktop\LandRecords_PBL\25CSMR09\LandRecords_extracted\client npm install npm run dev
✔ Open your browser at: http://localhost:3000
