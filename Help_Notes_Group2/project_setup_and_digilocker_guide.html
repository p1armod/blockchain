Can You Run This Directly on Your Windows Machine?

Yes, absolutely! Hyperledger Fabric networks are designed to run inside Linux containers. Since you already have Docker Desktop and WSL2 (Ubuntu) installed on Windows, your system has everything required to run this project smoothly.

✅
Why WSL2 + Docker Desktop Is Ideal
• WSL2 gives you a native Ubuntu Linux environment to execute shell scripts (.sh).
• Docker Desktop automatically manages all Hyperledger Fabric peers, orderers, CAs, and CouchDB containers.
• You only need the 25CSMR09/LandRecords_extracted folder — all chaincode, fabric scripts, API, and Next.js client are inside it!
💡
Key Rule for Windows + WSL Setup
• DO NOT run network setup scripts directly inside Windows PowerShell.
• DO open your WSL Ubuntu terminal to execute the ./setup-network.sh shell script.
• You can access the Next.js Web UI right from your Windows browser at http://localhost:3000.

How DigiLocker Is Used & How to Integrate It

DigiLocker acts as the government-trusted identity and document verification bridge in this project. It ensures that uploaded property deeds and Aadhaar cards are authentic and tamper-evident before being anchored on the blockchain.

▶ DIGILOCKER DOCUMENT VERIFICATION ARCHITECTURE
1. Official Requests Document
Org2 Clerk requests Aadhaar / Deed via Admin Panel
→
2. Notification to Citizen
Citizen gets alert in DigiLocker Vault UI
→
3. Citizen Grants Access
Citizen approves request with 1-click
→
4. SHA-256 + IPFS Upload
Document pinned to IPFS, SHA-256 hash computed
→
5. Blockchain Anchoring
IPFS hash + SHA-256 saved immutably on Fabric

1. Current Implementation in the Project

In 25CSMR09/LandRecords_extracted, DigiLocker is implemented using a Local Government Vault Simulation + Pinata IPFS Gateway:

• DigiLockerVault.ts: Stores citizen verified identity documents locally in MongoDB.
• DigiLockerRequest.ts: Tracks official document requests (Pending, Approved, Rejected).
• api/digilocker/respond/route.ts: When citizen clicks "Approve", the server computes a SHA-256 cryptographic hash, uploads the document to IPFS (Pinata), and writes the immutable IPFS address + hash directly onto the Hyperledger Fabric blockchain ledger!

2. How to Configure / Integrate It Locally

To run DigiLocker features locally, set these environment variables in client/.env.local:

# client/.env.local MONGODB_URI="mongodb://localhost:27017/land_records" NEXT_PUBLIC_FABRIC_API_URL="http://localhost:3001" # IPFS Pinata Keys (Optional - uses local hash fallback if omitted) PINATA_API_KEY="your_pinata_api_key" PINATA_SECRET_KEY="your_pinata_secret_key"
