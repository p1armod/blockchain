Feature Overview

What Is Joint Ownership?

Joint ownership allows a single land record to be registered in the name of multiple co-owners (e.g., husband + wife, family members, business partners). All owners must give their digital consent for the registration to proceed. Every co-owner's share percentage is recorded on the blockchain permanently.

✅
What Changes in the Existing System
  • The application object gains a new owners[] array field (replaces single owner)
  • createApplication() is modified to accept multiple owners with share percentages
  • A new consent mechanism is added — all co-owners must sign digitally
  • New ownership transfer function for when one co-owner sells their share
  • New co-owner dispute flag that freezes the land record
  • No new organizations, No new Docker configs — only chaincode + API + UI changes
⚠️
Business Rules (Must Enforce in Chaincode)
  • All co-owners' share percentages must sum to exactly 100%
  • Minimum 2, maximum 5 co-owners per land record
  • An owner cannot hold less than 1% share
  • All co-owners must provide consent before status progresses past submitted
  • Any partial share transfer requires other co-owners' approval
  • A disputed record is frozen — no status change until dispute resolved
💡
Why This Works Without a New Organization
Joint ownership is a data model change + new business logic — it does not require a new endorser or a new MSP. The same 3 existing organizations (Org1 Registration, Org2 Revenue, Org3 Collectorate) process the application. The only thing that changes is:

① The asset schema has a richer ownership structure
② The consent from co-owners is tracked on-chain
③ New chaincode functions handle co-owner operations
④ The frontend shows a multi-owner application form

This is 100% backward-compatible with existing single-owner applications.

Chaincode Design

5 New + 2 Modified Smart Contract Functions

All functions go inside LandRegistrationContract class in land-registration-contract.js. Green = new, Yellow = modified existing.

addCoOwnerConsent(applicationId, ownerId, consentData)
NEW FUNCTION
Called by each co-owner to digitally approve their co-ownership. Checks the caller's ID matches one of the listed owners. Updates consentStatus: 'approved' for that owner. When all owners have consented, sets allConsentsGiven = true. Records event in history[].
👤 Called by: Each co-owner individually (any org)
transferOwnershipShare(applicationId, fromOwnerId, toOwnerId, sharePercent)
NEW FUNCTION
Transfers sharePercent from one owner to another (existing or new person). Validates: shares still sum to 100%, record must be completed status, record is not disputed. Requires approval from all other co-owners (tracked via a transferApprovals[] sub-array). Logs transfer event.
👤 Called by: Property owner (Org1 MSP)
raiseOwnershipDispute(applicationId, raisedBy, reason)
NEW FUNCTION
Sets isDisputed = true on the application object. Records dispute details (who raised it, reason, timestamp). Any co-owner can call this. A disputed record cannot be forwarded in the workflow — guarded in forwardApplication().
👤 Called by: Any co-owner (any org)
resolveOwnershipDispute(applicationId, resolutionDetails)
NEW FUNCTION
Sets isDisputed = false. Records the resolution decision and by whom. Can only be called by Org3 (Collectorate/Collector role). Unfreezes the application so workflow can continue. Logs resolution event in history[].
🔑 Only Org3MSP — Collector or Joint Collector
getOwnershipDetails(applicationId)
NEW READ FUNCTION
Read-only query. Returns full ownership breakdown: each owner's name, Aadhaar (decrypted), share %, consent status, and consent timestamp. Also returns allConsentsGiven, isDisputed, and dispute details if applicable.
📊 Any org — read-only, no state change
createApplication() — MODIFIED
MODIFIED EXISTING
Add new fields to the application object: owners: [], ownershipType: 'single'|'joint', allConsentsGiven: false, isDisputed: false, disputeDetails: null. For ownershipType='joint', build the owners array from transient data. Validate share percentages sum to 100%.

STEP 2: addCoOwnerConsent() — Complete new function

/** * M10: Co-owner provides digital consent to the joint ownership application * Called individually by each co-owner listed in the owners[] array */ async addCoOwnerConsent(ctx, applicationId, ownerId, consentDataStr) { console.info('===== addCoOwnerConsent START ====='); const cid = new ClientIdentity(ctx.stub); const callerEnrollmentId = cid.getAttributeValue('hf.EnrollmentID') || ownerId; const applicationAsBytes = await ctx.stub.getState(applicationId); if (!applicationAsBytes || applicationAsBytes.length === 0) { throw new Error(`Application ${applicationId} does not exist`); } const application = JSON.parse(applicationAsBytes.toString()); // Only valid for joint applications if (application.ownershipType !== 'joint') { throw new Error('This is not a joint ownership application'); } // Find the owner in the owners array by ownerId const ownerIndex = application.owners.findIndex(o => o.ownerId === ownerId); if (ownerIndex === -1) { throw new Error(`Owner ${ownerId} is not listed as a co-owner for this application`); } if (application.owners[ownerIndex].consentStatus === 'approved') { throw new Error(`Owner ${ownerId} has already given consent`); } const consentData = JSON.parse(consentDataStr); const timestamp = ctx.stub.getTxTimestamp().seconds.toString(); // Update the specific owner's consent status application.owners[ownerIndex].consentStatus = 'approved'; application.owners[ownerIndex].consentTimestamp = timestamp; application.owners[ownerIndex].consentRemarks = consentData.remarks || 'Consent given'; // Check if ALL owners have now consented const allConsented = application.owners.every(o => o.consentStatus === 'approved'); application.allConsentsGiven = allConsented; application.updatedAt = timestamp; const txId = ctx.stub.getTxID(); const transactionId = 'TXN-' + timestamp + '-' + txId.substr(0, 8); application.history.push({ transactionId, officialId: callerEnrollmentId, officialName: callerEnrollmentId, designation: 'co_owner', action: 'consent_given', remarks: `Co-owner ${ownerId} consented. All consented: ${allConsented}`, timestamp, data: { ownerId, sharePercent: application.owners[ownerIndex].sharePercent }, documents: [] }); await ctx.stub.putState(applicationId, Buffer.from(JSON.stringify(application))); console.info('===== addCoOwnerConsent END ====='); return JSON.stringify({ message: allConsented ? 'All co-owners have consented. Application can now be forwarded.' : 'Consent recorded. Waiting for other co-owners.', allConsentsGiven: allConsented, owners: application.owners }); }
STEP 3: raiseOwnershipDispute() — Complete new function
NEW
/** * M11: Any co-owner raises a dispute, freezing the application */ async raiseOwnershipDispute(ctx, applicationId, raisedBy, reason) { console.info('===== raiseOwnershipDispute START ====='); const applicationAsBytes = await ctx.stub.getState(applicationId); if (!applicationAsBytes || applicationAsBytes.length === 0) { throw new Error(`Application ${applicationId} does not exist`); } const application = JSON.parse(applicationAsBytes.toString()); if (application.ownershipType !== 'joint') { throw new Error('Disputes can only be raised for joint ownership applications'); } if (application.isDisputed) { throw new Error('Application already has an active dispute'); } // Verify the raiser is a listed co-owner const isOwner = application.owners.some(o => o.ownerId === raisedBy); if (!isOwner) { throw new Error(`${raisedBy} is not a listed co-owner and cannot raise a dispute`); } const timestamp = ctx.stub.getTxTimestamp().seconds.toString(); application.isDisputed = true; application.disputeDetails = { raisedBy, reason, timestamp, resolvedAt: null }; application.updatedAt = timestamp; const txId = ctx.stub.getTxID(); application.history.push({ transactionId: 'TXN-' + timestamp + '-' + txId.substr(0, 8), officialId: raisedBy, officialName: raisedBy, designation: 'co_owner', action: 'dispute_raised', remarks: `DISPUTE: ${reason}. Application FROZEN.`, timestamp, data: { raisedBy, reason }, documents: [] }); await ctx.stub.putState(applicationId, Buffer.from(JSON.stringify(application))); console.info('===== raiseOwnershipDispute END ====='); return JSON.stringify({ message: 'Dispute raised. Application is now FROZEN. Contact Collectorate to resolve.', disputeDetails: application.disputeDetails }); }
STEP 4: resolveOwnershipDispute() — Complete new function
NEW
/** * M12: Org3 Collector resolves the dispute, unfreezing the application */ async resolveOwnershipDispute(ctx, applicationId, resolutionDataStr) { console.info('===== resolveOwnershipDispute START ====='); const cid = new ClientIdentity(ctx.stub); const mspId = cid.getMSPID(); // Only Org3 (Collectorate) can resolve disputes if (mspId !== 'Org3MSP') { throw new Error('Only the Collectorate (Org3) can resolve ownership disputes'); } const applicationAsBytes = await ctx.stub.getState(applicationId); if (!applicationAsBytes || applicationAsBytes.length === 0) { throw new Error(`Application ${applicationId} does not exist`); } const application = JSON.parse(applicationAsBytes.toString()); if (!application.isDisputed) { throw new Error('This application has no active dispute to resolve'); } const resolution = JSON.parse(resolutionDataStr); const timestamp = ctx.stub.getTxTimestamp().seconds.toString(); application.isDisputed = false; application.disputeDetails.resolvedAt = timestamp; application.disputeDetails.resolution = resolution.decision; application.disputeDetails.resolvedBy = cid.getAttributeValue('hf.EnrollmentID') || 'collector'; application.updatedAt = timestamp; const txId = ctx.stub.getTxID(); application.history.push({ transactionId: 'TXN-' + timestamp + '-' + txId.substr(0, 8), officialId: application.disputeDetails.resolvedBy, officialName: application.disputeDetails.resolvedBy, designation: 'joint_collector', action: 'dispute_resolved', remarks: `Dispute resolved. Decision: ${resolution.decision}. Application UNFROZEN.`, timestamp, data: resolution, documents: [] }); await ctx.stub.putState(applicationId, Buffer.from(JSON.stringify(application))); console.info('===== resolveOwnershipDispute END ====='); return JSON.stringify({ message: 'Dispute resolved. Application is now active again.', application }); }

fabric-api/src/jointOwnershipRoutes.js — New file (Member 2 creates this)
API
const express = require('express'); const router = express.Router(); const { getGateway } = require('./fabricClient'); const { getUserOrg } = require('./userOrgMap'); // POST /api/land/joint - Create joint ownership application router.post('/joint', async (req, res) => { try { const { applicationId, owners, primaryOwner } = req.body; // owners = [{ ownerId, name, aadhar, sharePercent }, ...] const totalShare = owners.reduce((s, o) => s + parseFloat(o.sharePercent), 0); if (Math.abs(totalShare - 100) > 0.01) return res.status(400).json({ error: `Shares must total 100%. Got: ${totalShare}%` }); const { gateway, network } = await getGateway(getUserOrg(primaryOwner)); const contract = network.getContract('land-registration'); const transientData = { userData: Buffer.from(JSON.stringify({ ...req.body, ownershipType: 'joint', owners })) }; const result = await contract.createTransaction('createApplication').setTransient(transientData).submit(applicationId); gateway.disconnect(); res.json(JSON.parse(result.toString())); } catch(e) { res.status(500).json({ error: e.message }); } }); // POST /api/land/:id/consent - Co-owner gives consent router.post('/:id/consent', async (req, res) => { try { const { ownerId, remarks, username } = req.body; const { gateway, network } = await getGateway(getUserOrg(username)); const contract = network.getContract('land-registration'); const result = await contract.submitTransaction('addCoOwnerConsent', req.params.id, ownerId, JSON.stringify({ remarks })); gateway.disconnect(); res.json(JSON.parse(result.toString())); } catch(e) { res.status(500).json({ error: e.message }); } }); // POST /api/land/:id/dispute - Raise ownership dispute router.post('/:id/dispute', async (req, res) => { try { const { raisedBy, reason, username } = req.body; const { gateway, network } = await getGateway(getUserOrg(username)); const contract = network.getContract('land-registration'); const result = await contract.submitTransaction('raiseOwnershipDispute', req.params.id, raisedBy, reason); gateway.disconnect(); res.json(JSON.parse(result.toString())); } catch(e) { res.status(500).json({ error: e.message }); } }); // PUT /api/land/:id/dispute/resolve - Collector resolves dispute router.put('/:id/dispute/resolve', async (req, res) => { try { const { decision, username } = req.body; const { gateway, network } = await getGateway('Org3MSP'); // Only Org3 const contract = network.getContract('land-registration'); const result = await contract.submitTransaction('resolveOwnershipDispute', req.params.id, JSON.stringify({ decision })); gateway.disconnect(); res.json(JSON.parse(result.toString())); } catch(e) { res.status(500).json({ error: e.message }); } }); // GET /api/land/:id/owners - Get ownership details router.get('/:id/owners', async (req, res) => { try { const { gateway, network } = await getGateway('Org1MSP'); const contract = network.getContract('land-registration'); const result = await contract.evaluateTransaction('getOwnershipDetails', req.params.id); gateway.disconnect(); res.json(JSON.parse(result.toString())); } catch(e) { res.status(500).json({ error: e.message }); } }); module.exports = router;
