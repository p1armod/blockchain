🇮🇳DigiLocker Kya Hota Hai?

🗣️ Simple Hinglish Mein Samjho

Socho jaise tumhare ghar mein ek almirah (locker) hai jahan tumhare sabhi important documents rakhe hain — Aadhaar card, land deed, certificate, etc.

DigiLocker usi almirah ka digital version hai. Government ka digilocker.gov.in bhi yahi karta hai — documents digitally store karta hai.

Hamare project mein hum apna khud ka ek chhota DigiLocker bana rahe hain — ek database jahan citizen ke documents (Aadhaar, Land deed) safely store hote hain, aur government officials usse permission lekar access kar sakte hain.

✅Project Mein Already Kya Hai?

🎉
Good News! DigiLocker ka poora system already coded hai. Tumhare groupmate (Charita Priya - Org2) ne yeh module implement kiya tha (M7_PRIVACY_SECURITY). Tumhe sirf configure aur run karna hai.
📦 DigiLockerVault (Database Model)

Citizen ke documents (Aadhaar card, Land deed) ko MongoDB mein store karta hai. Base64 PDF as file data, IPFS hash bhi store hota hai approval ke baad.

📩 DigiLockerRequest (Request Model)

Jab koi official kisi citizen ka document maangta hai — yeh request yahan store hoti hai with status: pending / approved / rejected.

🔗 API Routes (3 Routes)

/api/digilocker (fetch requests), /api/digilocker/request (create), /api/digilocker/respond (citizen approve/reject).

🌐 IPFS Upload (Pinata)

Jab citizen approve karta hai — document Pinata IPFS par upload hota hai, SHA-256 hash generate hota hai, aur blockchain par record hota hai.

⛓️ Blockchain Record

IPFS hash + document integrity hash Hyperledger Fabric par permanently store hota hai — tamper-proof record!

💻 UI Pages

/digilocker (citizen dashboard) aur /digilocker-admin (official dashboard) — dono pages already banae hue hain.

🔄Poora Flow Kaise Kaam Karta Hai?

🗣️ Example se Samjho

Ramesh (citizen) apni land registration ke liye apply karta hai.
Revenue Clerk (official) ko Ramesh ka Aadhaar verify karna hai.

Clerk DigiLocker se Ramesh ka Aadhaar document maangta hai → Ramesh ko notification aata hai → Ramesh approve karta hai → Document IPFS par upload hota hai → Hash blockchain par store hota hai → Clerk document dekh sakta hai. Done! 🎉

1
🏛️ Admin uploads document to DigiLocker Vault

Government authority (admin) citizen ka Aadhaar card ya Land Deed DigiLocker Vault mein upload karta hai. MongoDB mein base64 format mein store hota hai.

POST /api/digilocker-vault MongoDB DigiLockerVault collection
2
👮 Official creates document access request

Revenue Clerk citizen ka document access karna chahta hai. Woh ek request create karta hai linked to citizen username.

POST /api/digilocker Status: pending
3
👤 Citizen sees pending request

Citizen apne DigiLocker dashboard (/digilocker) mein login karta hai. Pending requests dikhti hain. Approve ya Reject?

GET /api/digilocker DigiLockerRequestPanel UI
4
✅ Citizen APPROVES → Auto Magic Happens!

Server automatically: Vault se document nikalta hai → SHA-256 hash generate karta hai → Pinata IPFS par upload karta hai → Hash vault mein save karta hai.

POST /api/digilocker/respond {action: approved}
5
⛓️ Blockchain par permanently record hota hai

IPFS hash aur SHA-256 hash Hyperledger Fabric blockchain par record hota hai — tamper-proof permanent record!

Fabric API recordDocumentIntegrity chaincode
6
🏛️ Official document access karta hai

Official ko IPFS hash milta hai. IPFS gateway se actual document download kar sakta hai aur hash verify kar sakta hai ki document authentic hai.

https://ipfs.io/ipfs/{hash} Verification complete ✅

⚙️Setup Kaise Karein? (Step-by-Step)

⚠️
Pehle check karo: Docker Desktop + WSL2 Ubuntu + Node.js installed hone chahiye. Hyperledger Fabric network bhi running hona chahiye.

Step 1: Pinata Account Banao (Free — IPFS ke liye)

1
pinata.cloud par jaao aur free account banao

Browser mein https://pinata.cloud open karo → Sign Up karo. Free plan mein 1GB storage milta hai — project ke liye kaafi hai.

2
API Keys generate karo

Login ke baad: API Keys section → "New Key" click karo → API Key aur Secret Key copy karo — .env.local mein jayenge.

Step 2: MongoDB Install aur Start Karo

🍏 Ubuntu WSL Terminal mein chalao 
# MongoDB install karo (agar nahi hai)
sudo apt-get update && sudo apt-get install -y mongodb

# MongoDB service start karo
sudo service mongodb start

# Status check karo (running dikhna chahiye)
sudo service mongodb status

# Ya Docker se MongoDB chala sakte ho (easier!)
docker run -d --name mongodb -p 27017:27017 mongo:latest

Step 3: .env.local File Configure Karo

📝 File location: client/.env.local (agar nahi hai to naya banao)

Yeh file project ka secret configuration file hai. Isme API keys aur database URL store hoti hai. Kabhi bhi GitHub par push mat karo!

📄 client/.env.local — copy-paste karo, apni values daalo 
# ============================================
# MongoDB (DigiLocker Vault + Request storage)
# ============================================
MONGODB_URI=mongodb://localhost:27017/landrecords
# Agar MongoDB Atlas use kar rahe ho:

NEXTAUTH_URL=http://localhost:3000
